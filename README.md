带宽往上加，价格涨得不线性：50M的IEPL/IPLC专线年费大约8万-20万，100M及以上普遍15万-40万起步；如果只是多分支组网、预算有限，MPLS或SD-WAN方案大约1万-10万一年。

换算成月费更好理解。香港方向大约300元/M·月，10M就是一个月3000元上下；电信到美国、德国约300-400元/M/月；移动到美国等地区，有用户反馈在400-600元/M/月；联通的东南亚线路也有约300元/M/月的反馈。中东、非洲方向因为要绕行转接，明显更贵。

办之前还有两件事要有数：这些专线只面向企业客户，要提供营业执照等资质材料；从签约到开通常见2-6周，海外端节点越偏，时间越长。

## 同样是10M，为什么有人报3万、有人报8万

报价差异主要来自五处：带宽、线路类型、两端城市、合约年限和SLA。10M和100M的年费可能相差5-8倍；IEPL/IPLC点对点独享最贵，MPLS次之，SD-WAN借助公共网络叠加优化，成本能低30%-50%。国内端在北上广深接入便宜，二三线城市有额外费用；海外端香港、新加坡、日本线路资源充足价格低，欧美和冷门地区要绕行。签长约通常能谈下10%-20%，同是10M，上海到香港和内陆城市到香港也可能差出30%以上。

### 共享和独享，是两种商品

最容易踩的坑在这里。**100M共享带宽和100M独享带宽是两种不同的商品**：共享线路由多个用户分摊资源，报价低，但高峰期没有任何保障。市面上几百元的“100M跨境网络”，不能拿来和10M企业独享专线比价。两家报价差出好几倍时，先确认是不是同样的地区、同样的带宽类型、相近的SLA和IP条件，否则比不出任何结论。

IP也是一样的道理：共享IP、独享静态IP、原生IP、住宅IP的价格差很多，业务需要多国独享住宅IP的话，整体费用会明显上浮。

## 报价单之外，这五笔钱和三条条款先抠清楚

报价单上的数字只是开始，签约前把下面几笔问清楚：

- 初装费与工程费：上门安装调测是否另收费
- 设备费：CPE终端是租赁、免费提供还是要购买，升级收不收费
- 带宽调整费：之后升降带宽有多灵活，收多少
- 备份链路流量费：内置4G/5G备份在海外产生的流量怎么计
- 技术服务费：7x24支持是标配，还是分等级收费

把这些写成合同附件，比口头承诺有用得多。

SLA条款同样有三个细节值得抠。可用性承诺99.9%，意味着每月允许约43分钟不可用，先想清楚你的业务接受哪一档。时延承诺要确认写的是平均值还是P95最高值，两者差别不小。免责条款最关键：SLA保障的是运营商自有网络段，还是端到端全程——有企业因为没核对这条，第三方网络出问题时拿不到赔偿。丢包率通常承诺不超过0.5%，对视频会议和通话质量的影响很直接。

## 你需要多大带宽：按人数和业务算

带宽按人均0.5M到1M估算，再留余量。20人以内的日常办公、收发邮件和网页操作，10M基本够用；有大量文件同步或频繁视频会议，从50M起步；10人左右的小团队，5M独享专线通常是够的。

业务类型也影响这个数：普通外贸办公主要看稳定性和成本；海外直播重点看上行带宽、延迟和丢包率；AI研发和大数据同步看并发和大文件传输。按实际并发算，别按“公司多少人”拍脑袋，更别为闲置带宽买单。

算下来运营商专线超预算的话，还有三档更轻的选择。

## 常见问题

**个人能办理跨境专线吗？**
三大运营商的跨境专线只面向企业客户，办理要提供营业执照等资质材料。个人或小团队有跨境业务需求，走账号型方案或代理IP这一档更现实。

**几百块的“100M跨境专线”能买吗？**
先确认是共享还是独享。共享带宽由多个用户分摊线路资源，高峰期没有保障，和企业独享专线不是同一类商品，直接比价格没有意义。

**专线一定要签一年以上吗？**
运营商专线基本按年起签，月付价格贵很多，还通常要收初装费。业务周期不确定的话，可以先用SD-WAN这类灵活方案过渡。

**从签约到开通要多久？**
常见周期2-6周，取决于两端城市的资源情况，海外端节点越偏越长。签合同时把施工周期和对应责任写清楚。
